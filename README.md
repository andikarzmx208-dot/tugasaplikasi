# WAROENG CiTUT — HTML + CSS + JavaScript + PHP + MySQL

Project ini dibuat sebagai dasar aplikasi/website pemesanan makanan sesuai referensi.

## 1. Teknologi
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## 2. Menjalankan tampilan
Jika hanya ingin melihat tampilan, buka `index.html`.

## 3. Menjalankan PHP + MySQL
Install XAMPP lalu:
1. Aktifkan Apache dan MySQL.
2. Salin folder `warung-citut` ke `C:\xampp\htdocs\`.
3. Buka phpMyAdmin.
4. Import `database/warung_citut.sql`.
5. Buka `http://localhost/warung-citut/`.

## 4. Struktur
index.html
css/style.css
js/app.js
php/config.php
php/login.php
php/register.php
php/logout.php
php/menu.php
php/order.php
database/warung_citut.sql

## 5. Catatan
Frontend saat ini memakai data JavaScript agar bisa langsung dicoba tanpa backend. File PHP + SQL sudah disediakan untuk tahap koneksi database.
